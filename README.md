## 🎯 Что это?

**Anti-AI Qwen Companion** — это не просто ещё один чат с ИИ. Это **мета-инструмент**, который учит *как* правильно работать с искусственным интеллектом:

- 📚 **Интерактивный курс** по формуле идеального промпта
- 🎨 **Конструктор запросов** (Role + Context + Task + Constraints)
- 🧠 **Тренажёр критического мышления** (проверка на галлюцинации ИИ)
- 🔐 **Сканер приватности** (автоматическое обнаружение чувствительных данных)
- 🏆 **Система достижений** и сертификат по окончании
